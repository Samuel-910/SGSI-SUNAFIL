# Análisis Organizacional SUNAFIL - UPEU

## 📋 Descripción del Proyecto
Este proyecto es una presentación interactiva tipo *landing page* que expone un **Análisis Organizacional y de Planeamiento Estratégico** detallado de **SUNAFIL** (Superintendencia Nacional de Fiscalización Laboral del Perú). Fue desarrollado como parte de un trabajo académico para la **Universidad Peruana Unión (UPEU)**.

El sitio web documenta aspectos clave de la gestión corporativa de la institución, abarcando desde su filosofía organizacional hasta sus mecanismos de control y estructura.

## 🗂️ Estructura del Contenido
El análisis se divide en las siguientes áreas principales:
1. **Aspectos Generales:** Historia, sedes, proveedores, servicios y análisis de la imagen institucional.
2. **Planeamiento Estratégico:** Visión, misión, cultura organizacional, análisis estratégico (FODA, CAME, matrices) y Mapa Estratégico.
3. **Control Estratégico:** Cuadro de Mando Integral (Balanced Scorecard / BSC) y sistemas de información.
4. **Dirección Estratégica:** Implantación de estrategias y manuales de gestión (MOF, ROF y CAP).
5. **Anexos:** Documentos oficiales (PDFs) adjuntos y evidencias fotográficas de las exposiciones y visitas.

## 🛠️ Tecnologías Utilizadas
- **HTML5:** Estructura de la página web.
- **Tailwind CSS (vía CDN):** Framework para el diseño responsivo, estilos visuales y estructuración de la interfaz.
- **FontAwesome:** Para la iconografía del sitio.

## 🚀 Cómo usar y visualizar el proyecto
Al ser un proyecto estático básico (frontend), no se requiere la instalación de dependencias de Node.js, servidores locales, ni bases de datos.

1. Clona o descarga este repositorio (`admin`) en tu computadora.
2. Abre la carpeta del proyecto en tu explorador de archivos.
3. Haz **doble clic en el archivo `index.html`**. Este se abrirá automáticamente en tu navegador web predeterminado (Chrome, Edge, Firefox, etc.).
4. Usa el menú de navegación superior para saltar fácilmente entre las diferentes secciones y visualizar las fotos y documentos integrados.

*Nota: Asegúrate de tener conexión a internet al abrir el archivo, ya que el diseño (Tailwind) y los iconos (FontAwesome) se cargan desde repositorios en línea (CDNs).*
